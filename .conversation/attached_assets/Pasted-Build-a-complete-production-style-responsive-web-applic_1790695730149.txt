Build a complete production-style responsive web application called SEVA AI — Public Service Navigator Agent.

IMPORTANT:
This is NOT a simple chatbot, landing page, or static UI. Build it as a realistic full-stack application that could eventually be used by citizens across India.

The application helps users describe a real-life need in natural language and then uses an agentic workflow to discover potentially relevant public/government services, identify missing information, organize required documents, explain next steps, and help users track their service journey.

Do NOT claim guaranteed eligibility or make up government schemes. Government-service information must be represented as verified data with an official source URL and verification date. If information is unavailable, clearly say that it needs verification.
